# 不良事件上报 · 中美欧时限与流程速查

> 上市后PMS最重要的一件事：不良事件按时限上报。漏报、瞒报、晚报都是违法。

---

## 一、什么是医疗器械不良事件（MDR AE）

**定义**：获准上市的、合格的医疗器械在正常使用情况下，发生的导致或可能导致人体伤害的各种有害事件。

### 上报类型

| 类型 | 说明 |
|------|------|
| 严重不良事件 | 导致死亡、严重伤害、危及生命 |
| 一般不良事件 | 不构成严重伤害但可能有影响 |
| 濒临事件（near miss） | 差点发生但没有发生的隐患 |

---

## 二、美国FDA · MDR（21 CFR 803）

### 上报时限

| 事件类型 | 时限 | 报告类型 |
|---------|------|---------|
| 死亡 | **30个日历日** | MDR |
| 严重伤害 | **30个日历日** | MDR |
| 可能导致死亡/严重伤害的故障 | **30个日历日** | MDR |
| 补救措施（Recall/FSCA） | 5个工作日内通知 | Correction/Removal Report |
| 趋势分析发现问题 | 按规定 | Annual Report |

### 谁来报

- **制造商**：直接报FDA（Form 3500A）
- **进口商**：报制造商和FDA
- **使用单位（医院）**：报制造商，严重的也报FDA
- **用户报告**：患者可直接向FDA MedWatch报告

### 上报渠道

- FDA电子提交系统（eMDR）
- 网址：https://www.accessdata.fda.gov/scripts/medwatch/

---

## 三、欧盟MDR · 警戒系统（Vigilance）

### 上报时限（Article 87）

| 事件类型 | 时限 |
|---------|------|
| 死亡/严重健康恶化 | **10日内** |
| 严重事件（不含死亡） | **15日内** |
| 一般事件 | 按PSUR周期汇总 |
| 现场安全纠正措施（FSCA） | **10日内** |
| 死亡或严重伤害的趋势报告 | 按主管当局要求 |

### 报告对象

- **主管当局（Competent Authority）**：事件发生地成员国
- **公告机构（NB）**：同时通知
- **EUDAMED**：欧盟统一数据库
- 报告类型：MIR（Manufacturer Incident Report）、FSCA报告、PSUR

### 报告内容（MIR）

- 事件描述
- 器械信息（UDI、型号、批次）
- 患者/使用者情况
- 事件后果
- 调查结论
- 纠正措施

---

## 四、中国NMPA · 不良事件监测

### 上报时限（《医疗器械不良事件监测和再评价管理办法》）

| 事件类型 | 时限 |
|---------|------|
| 导致死亡 | **7日内** |
| 导致严重伤害、可能导致严重伤害或死亡 | **20日内** |
| 一般不良事件 | **30日内** |
| 群体性不良事件 | 立即报告（**24小时内**） |

### 上报渠道

- 国家医疗器械不良事件监测信息系统（NMPA）
- 网址：https://www.mdaudit.cn
- 报告类型：个例报告、群体报告、定期风险评价报告

### 注册人义务

- 建立不良事件监测制度
- 配备专职监测人员
- 主动收集（医院反馈、投诉、文献、监管信息）
- 调查、评价、上报
- 必要时开展再评价、召回

## 五、三地时限对比表

| 事件类型 | 美国FDA | 欧盟MDR | 中国NMPA |
|---------|---------|---------|---------|
| 死亡 | 30天 | 10天 | **7天** |
| 严重伤害 | 30天 | 15天 | 20天 |
| 一般事件 | 年度汇总 | PSUR | 30天 |
| 群体性事件 | 立即 | 立即 | 24小时 |
| 召回/FSCA | 5工作日 | 10天 | 立即 |

> ⚠️ 中国时限最严，死亡7天内必须报。

## 六、PMS体系核心文件

| 文件 | 美国 | 欧盟 | 中国 |
|------|------|------|------|
| 上市后监督计划 | PMS Plan | PMS Plan（强制） | PMS制度 |
| 定期安全更新报告 | Annual Report | PSUR（Class IIa 2年/IIb 1年/III 1年） | 定期风险评价报告（年度） |
| 上市后临床随访 | PMCF（按需） | PMCF（强制，Class IIa以上） | PMCF（按需） |
| 严重事件报告 | MDR 30天 | MIR 10-15天 | 个例7-20天 |
| 召回报告 | Correction/Removal | FSCA | 召回报告 |

## 七、P0级禁令

1. **🚫 不许瞒报**——瞒报、漏报是违法的，可吊销注册证、罚款、刑事责任
2. **🚫 不许超时**——每个市场时限不一样，按时报
3. **🚫 不许私下处理**——给医院"压下去"、私下赔偿，不通过监管渠道，违法
4. **🚫 不能只报不查**——报了之后要调查、评价、采取纠正措施

---

## 八、企业内部PMS流程

```
信息收集（医院/经销商/投诉/文献/监管）
   ↓
初步评价（是否构成不良事件？严重程度？）
   ↓
严重事件？→ 是 → 按时限上报（7/20/30天，10/15天，30天）
   ↓ 否
调查分析（根本原因、批次、范围）
   ↓
纠正预防措施（CAPA）
   ↓
定期汇总（PSUR/年度报告）
   ↓
更新风险管理文件
```

---

## 常见坑

1. **不重视一般事件**——一般事件积累起来可能是系统性问题
2. **以为"医院没报就没事"**——注册人有主动监测义务
3. **欧美市场忘了报**——出口企业最容易忽视境外PMS
4. **没有专职人员**——出了事没人知道怎么报
5. **没有保留记录**——监管检查时拿不出PMS证据
